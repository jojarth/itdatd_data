## Writing Rules with Keywords

Sooner or later you will write your own spells, features, items, and creatures. Keywords are what let those new pieces fit into the game without rewriting what already exists. A few habits keep them working.

### Target Keywords, Not Names
Write "**Insect** creatures", not "bugs". A rule that names a keyword automatically works with every creature that has it, including creatures that have not been written yet. A rule that names creatures in plain text has to be updated each time a new one appears.

### Target the Broadest Keyword That Works
If a spell calms any horse-like animal, target **Equine**. Only target **Horse** if the rule should affect horses and nothing else. Choose the category that matches what the rule is about:

- **Essence** for what sustains a creature (life-giving magic, turning the dead).
- **Form** for what its body can do (grappling, squeezing through gaps, area damage).
- **Species** for what it is (favored foes, mounts, ancestral grudges).
- **Adventure** for what has happened to it (curses, oaths, training).

### Summoned and Created Creatures
A feature that creates a creature should name its entry directly, such as "you summon a **Warhorse**", rather than describing it by keywords.

### Adding New Keywords
New keywords never break existing rules. If a rule needs a keyword that does not exist yet, add it to the creatures that should have it. Every rule that already targets those creatures continues to work.

What does cause trouble is renaming a keyword, or changing what an existing keyword covers. Avoid both once a keyword is in use.
