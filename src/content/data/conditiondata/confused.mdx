A **Confused** creature's mind is scrambled. It cannot tell friend from foe, and it does not fully control what it does.

**Behavior.** The effect that makes you Confused normally describes how you behave, often with its own table. If it does not, roll a d6 at the start of each round and behave as follows for that round:

| **d6** | **Behavior This Round** |
| --- | --- |
| **1** | Wander in a random direction, using all of your movement. |
| **2–3** | Stand dazed and do nothing. |
| **4–5** | Attack the nearest creature, friend or foe. |
| **6** | Act normally. |
