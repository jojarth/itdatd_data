---
datatype: hindrance
title: Attribute Failure
shortDescription: You automatically fail tests of the listed Attribute or Attributes.
valued: false
parameter: Attribute
tags:
- attributes
---

**Attribute Failure (Attribute)** causes you to automatically fail any Attribute Test using the listed Attribute. The listed Attribute can be a single Attribute, several Attributes, or one of the groups described under Attribute Penalty (physical, mental, or all).
