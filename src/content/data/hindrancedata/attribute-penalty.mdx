**Attribute Penalty (Attribute, X)** imposes a -X Condition modifier to Attribute Tests using the listed Attribute. The listed Attribute can be a single Attribute, several Attributes, or one of the following groups:

* **Physical:** Brawn, Heartiness, Agility, and Precision.
* **Mental:** Logic, Reason, Savvy, and Presence.
* **All:** every Attribute.

For example, Attribute Penalty (physical, 1) reduces your Brawn, Heartiness, Agility, and Precision by 1 when you test them.
