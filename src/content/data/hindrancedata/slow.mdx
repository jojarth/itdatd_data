**Slow (X)** reduces the number of Actions you have each round by its Slow value, to a minimum of 1 Action. For example, if you are Slow (1), you have 2 Actions each round instead of 3.

Slow does not reduce your number of Reactions or change how many Master Actions you can perform. If multiple effects make you Slow, use only the highest Slow value.

If another effect grants you additional Actions each round, subtract the smaller value from the larger and apply only the difference.
