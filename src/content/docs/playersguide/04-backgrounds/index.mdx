# Classes

Classes describe a character's core adventuring discipline: how they survive, solve problems, and grow in power.

## Class List

- [Magic-User](/playersguide/04-classes/magic-user/)

## Class Page Pattern

Each class page can contain a level table, a gameplay summary card, and feature cards for the rules a player needs at the table.
