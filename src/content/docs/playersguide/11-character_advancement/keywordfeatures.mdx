Keyword Features are special character options that turn the nature, heritage, training, and experiences represented by your keywords into a defining ability. Each Keyword Feature lists one or more prerequisite keywords, and you can select that feature only if your character possesses all of the listed prerequisites. Keyword Features are presented in this chapter and may also appear in campaign guides.

## Gaining a Keyword Feature

When you reach reache 5th level, select one Keyword Feature whose prerequisites you meet and gain its benefits. Consider every keyword your character possesses when determining which features are available to you, regardless of which class, ancestry, feature, or adventure granted the keyword.

A multi-class character gains only one Keyword Feature, taken when one of their classes first reaches 5th level. Reaching 5th level in another class does not grant an additional Keyword Feature.

Keyword Features are different from **Class Keyword Features**. A Class Keyword Feature is an ancestry feature selected during character creation based on one of your Class Keywords; a Keyword Feature is a separate character feature selected at 5th level and may use any of your keywords as prerequisites.
