Keyword Features are special character options that turn the nature, heritage, training, and experiences represented by your keywords into a defining ability. Each Keyword Feature lists one or more prerequisite keywords, and you can select that feature only if your character possesses all of the listed prerequisites. Keyword Features are presented in this chapter and may also appear in campaign guides.

## Gaining a Keyword Feature

Upon reaching 4th level, and again upon reaching 8th level, select one Keyword Feature whose prerequisites you meet and gain its benefits. Consider every keyword your character possesses when determining which features are available to you, regardless of which class, ancestry, feature, or adventure granted the keyword.

You cannot select the same Keyword Feature more than once. Once selected, a Keyword Feature cannot be exchanged for another unless its own rules say otherwise.

A multi-class character gains these Keyword Features when the first of their classes reaches 4th level and 8th level. Reaching those levels in another class does not grant additional Keyword Features. For example, a 5th-level Magic-User\8th-level Fighter gained their Keyword Features when their Fighter class reached 4th and 8th level, and could choose from features requiring either the **Arcanist** or **Soldier** keyword.

Some class features, such as the Fighter's Hard-Won Lessons, grant an additional Keyword Feature. These follow the same rules, along with any restrictions listed in the class feature.

Keyword Features are different from **Ancestral Training**. Ancestral Training is an ancestry feature granted during character creation based on one of your Archetype Keywords. A Keyword Feature is a separate character feature selected at 4th and 8th level, and may use any of your keywords as prerequisites, including those granted by your ancestry.
