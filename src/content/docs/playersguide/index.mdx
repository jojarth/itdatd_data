# Player's Guide

The Player's Guide contains the rules players use most often: character creation, classes, equipment, and combat.

## Chapters

- [Character Creation](/phb/character-creation/)
- [Classes](/phb/classes/)
- [Equipment](/phb/equipment/)
- [Combat](/phb/combat/)

## What This Book Covers

This book is intended to answer the questions a player will ask most often during character creation and play.

Use it to build characters, learn the core rules, and look up the systems that come up during sessions.
