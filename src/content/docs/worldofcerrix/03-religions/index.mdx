# Chapter 03: Religions

There are several major religions in Cerrix, and several minor ones as well. This chapter describes the major religions:

* **The Patristic Faith**, which teaches that all creation proceeds from a single God, the Father.
* **The Old Ways**, a collection of customs and beliefs that teach the world was torn from chaos through struggle, sacrifice, and blood.
