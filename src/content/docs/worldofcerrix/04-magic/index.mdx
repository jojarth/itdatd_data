# Chapter 04: Magic

This chapter describes magic in Cerrix in two parts:

* **The Nature of Magic** explains what magic truly is and how it works. It is meant for Game Masters and world builders, and its truths should never be discovered in play.
* **Magic in Cerrix** describes how the peoples of Cerrix learned magic and how they practice it today.
